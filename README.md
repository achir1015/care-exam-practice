# 照服員術科練習本

長期照顧服務員單一級術科技術士考試的手機練習網頁。

## 功能
- 7 題術科：操作步驟可勾選練習，紅線標示評分關鍵
- 重點與常見扣分、生命徵象正常值表
- 每題連到 Google Drive 示範影片
- 每題標示對應的攻略書頁碼，並連到 Google Drive 上的完整 PDF
- 跨題搜尋關鍵字

## 檔案結構
| 路徑 | 說明 |
|---|---|
| `index.html` | 主程式（單一 HTML，直接開啟即可） |
| `tools_split_pdf.py` | 切檔工具：依目錄頁碼把攻略 PDF 切成各題單頁 PDF（自用，產出檔案不放進本專案） |
